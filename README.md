# SlimeThrone Public Resource Pack

This repository is used to distribute the official resource pack for the **SlimeThrone Minecraft server network**.

The repository is public so Minecraft clients can download the resource pack when connecting to SlimeThrone. Public availability does **not** grant permission to reuse, redistribute, modify, repackage, or use the resource pack on other servers.

## Resource Pack

The current pack is distributed through GitHub Releases as:

`resource_pack.zip`

Players connecting to an authorized SlimeThrone server may have the pack downloaded and applied automatically by Minecraft.

## Usage

This resource pack is intended **only for authorized SlimeThrone servers**.

Use of the pack, its textures, models, sounds, fonts, configuration, or other included assets outside the SlimeThrone server network is not permitted unless explicit written permission is granted by SlimeThrone.
